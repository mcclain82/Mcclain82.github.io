LED BY LIGHT — TEST HOMEPAGE
October 23, 2026

DEPLOY TO NETLIFY
1. Extract the ZIP file.
2. Open https://app.netlify.com/drop in your browser.
3. Drag the extracted led-by-light-homepage folder into the deploy area.
   This is the folder containing index.html, styles.css, script.js and assets.
4. Open the preview URL Netlify gives you.

No build command, Node, package installation, API keys, or external asset CDN is needed.
You can also open index.html directly in a browser for a local preview.

SCOPE
This is a responsive, editable test homepage based on the selected concept:
- Stress Free / G&E in a bundled geometric font.
- Compact amber, teal, and terracotta service cards.
- Gaffer-at-work line illustration.
- Truck and carts illustration in the lower section.
- Mobile menu and keyboard-accessible links.

Services scrolls to the homepage service cards. Equipment, Work, About, quote,
and contact links go to the current ledbylight.net site. Other redesigned pages
and a new contact form are not part of this homepage test.

The hero photograph is AI-generated illustrative artwork. The block illustrations display the actual selected reference artwork through
cropped SVG viewports, replacing the simplified hand-drawn icons.
Truck: option 1. Lighting and Gaffer Services: option 2.
Original reference image files are bundled locally; no external image requests.
The geometric headline uses URW Gothic Demi. Body text uses Nimbus Sans.
All fonts are bundled locally; redistribution notices are in assets/FONT-LICENSE.txt.

Search indexing is disabled with robots.txt, a robots meta tag, and a Netlify
X-Robots-Tag header. These are not password protection.

EDITING
index.html: text, links, page structure
styles.css: colors, typography, spacing, responsive layout
script.js: mobile navigation
assets/: hero photo, block illustrations, font files

This package does not change or replace your Squarespace site or domain.

ARTWORK UPDATE: illustrations are larger and centered. Self-contained SVG assets
extract the original line art into an alpha channel, removing colored backgrounds.
